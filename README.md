
# Rock-paper-scissors-game
A simple and interactive Rock, Papper, Scissors game built with HTML, CSS and JavaScript

## Features
Choose Rock, Papper, or Scissors
Computer makes a random choice
display the winner of each round
Keeps track of the score
Reset the game

## Technologies

- HTML
- CSS
- JavaScript

## How it Works

The player chooses one of the three options: Rock, Papper, Scissors. The computer randomly selects an option, and javaScript compares both choices to determine the winner.

this project was created to improve my skills in JavaScript, DOM manipulation, event handling, and CSS.
